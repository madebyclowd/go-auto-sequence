# Security Policy

## Supported Versions

Only the latest release receives security fixes. While the module is below v1.0.0, that
means the latest v0 minor.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Report privately via GitHub's [Security Advisories](../../security/advisories/new) tab for this repository, or email **widiantara@clowdlab.com**.

Include:
- Description of the vulnerability and its impact
- Steps to reproduce (PoC if possible)
- Affected version(s)

You should receive a response within 5 business days. Confirmed vulnerabilities will be patched and disclosed via a GitHub Security Advisory with credit to the reporter, unless anonymity is requested.
